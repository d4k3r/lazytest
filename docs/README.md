# LazyTest documentation

This directory contains the public documentation assets for LazyTest.

- `lazytest_architecture.png` is the transparent source architecture diagram.
- `lazytest_architecture_github.png` is a non-destructive opaque rendering used by
  the root README so every label remains visible on light and dark GitHub pages.
- `results/` contains the dissertation result figures and interpretation notes.
- `reproducibility.md` describes the public reproduction boundary and setup.
- `licensing.md` explains which repository materials the software MIT licence covers.
- [`LazyTest_Dissertation.pdf`](LazyTest_Dissertation.pdf) is the redacted public
  dissertation containing the complete methodology, evaluation and limitations.

## Rights and scope

The repository's MIT licence applies only to project-specific software. Third-party
dependencies and evaluation repositories retain their own licences. The dissertation
PDF is a separate authored document and is not licensed under the software MIT
licence.

# LazyTest documentation

This directory contains the public documentation assets for LazyTest.

- `lazytest_architecture.png` is the transparent source architecture diagram.
- `lazytest_architecture_github.png` is a non-destructive opaque rendering used by
  the root README so every label remains visible on light and dark GitHub pages.
- `results/` contains the dissertation result figures and interpretation notes.
- `LazyTest_Dissertation.pdf` is the reserved path for a redacted public copy of
  the final dissertation. The private PDF containing the author's student identifier
  must not be committed.
